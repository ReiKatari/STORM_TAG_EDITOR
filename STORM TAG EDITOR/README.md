### 🇷🇺 Особенности программы (Russian)

1. **🎵 Мультиформатный редактор:** Поддержка MP3, FLAC, WAV, OGG, M4A, WMA, AIFF.
2. **🖼️ Управление обложками:** Drag & Drop, извлечение, установка, Full Screen просмотр.
3. **✂️ Аудио Триммер:** Точная обрезка треков с визуальным волновым графиком.
4. **🌊 Визуализация:** Живая отрисовка волны (Waveform) при воспроизведении.
5. **🔁 Аудио Конвертер:** Смена форматов, битрейта, частоты и сжатие.
6. **📝 Пакетное редактирование:** Массовое изменение тегов для целых альбомов.
7. **🎤 Редактор текста песен:** Встроенное поле для добавления Lyrics (текстов).
8. **🎧 Встроенный плеер:** Полноценное воспроизведение, перемотка, плейлист.
9. **🎚️ Эквалайзер:** Встроенные пресеты (Rock, Pop, Bass Boost и др.).
10. **💾 Авто-сохранение:** Надежная запись тегов ID3v2, Vorbis Comments.
11. **🌍 Локализация:** Полная поддержка Русского и Английского языков.
12. **🎨 Современный UI:** Тёмная тема, Glassmorphism эффекты и акцентные цвета.
13. **🖱️ Интуитивный слайдер:** Точная навигация по треку (Click-to-Seek).
14. **📂 Файловый менеджер:** Удобная навигация по папкам и фильтрация файлов.
15. **🔢 Авто-нумерация:** Умное заполнение номеров треков в один клик.
16. **🧹 Очистка тегов:** Возможность быстрого удаления обложек или всех метаданных.
17. **🔄 Авто-обновление:** Проверка новых версий на GitHub.
18. **⚡ Горячие клавиши:** Быстрое сохранение (Ctrl+S) и навигация.
19. **🛡️ Safe Mode:** Безопасная обработка файлов через FFmpeg.
20. **🚀 Портативность:** Работает как portable-приложение, настройки в JSON.

### 🇬🇧 Features (English)

1. **🎵 Multi-format Editor:** Support for MP3, FLAC, WAV, OGG, M4A, WMA, AIFF.
2. **🖼️ Cover Art Manager:** Drag & Drop, extraction, embedding, Full Screen view.
3. **✂️ Audio Trimmer:** Precise track trimming with visual waveform support.
4. **🌊 Visualization:** Live audio waveform rendering during playback.
5. **🔁 Audio Converter:** Convert formats, bitrates, sample rates, and compression.
6. **📝 Batch Editing:** Mass edit tags for entire albums or selections.
7. **🎤 Lyrics Editor:** Built-in field for adding and saving song lyrics.
8. **🎧 Integrated Player:** Full playback control with seeking and playlist.
9. **🎚️ Equalizer:** Built-in presets (Rock, Pop, Bass Boost, etc.).
10. **💾 Auto-Save:** Reliable tagging for ID3v2, Vorbis Comments, and more.
11. **🌍 Localization:** Full support for Russian and English languages.
12. **🎨 Modern UI:** Dark theme, Glassmorphism effects, and smooth animations.
13. **🖱️ Smart Slider:** Accurate Click-to-Seek navigation within tracks.
14. **📂 File Manager:** Easy folder navigation and file filtering.
15. **🔢 Auto-Numbering:** Smart one-click track numbering for albums.
16. **🧹 Tag Cleaning:** Option to quickly strip cover art or all metadata.
17. **🔄 Auto-Update:** Checks GitHub for the latest releases automatically.
18. **⚡ Hotkeys:** Quick Save (Ctrl+S) and navigation shortcuts.
19. **🛡️ Safe Mode:** Safe file processing powered by FFmpeg.
20. **🚀 Portable:** Runs as a portable app, settings saved in JSON.

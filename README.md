<h1 align="center">STORM TAG EDITOR</h1>

## **О проекте**
STORM TAG EDITOR — пакетный редактор метаданных (ID3v1, ID3v2.3, ID3v2.4, Vorbis Comments, APEv2, MP4 Tags) для музыкальных аудиофайлов всех форматов (MP3, FLAC, M4A, OGG, WAV, APE, OPUS). Позволяет встраивать обложки альбомов в высоком разрешении, нормализовать громкость (ReplayGain) и автоматически переименовывать файлы по настраиваемым паттернам.

## **Происхождение и форки**
Оригинальная разработка на базе открытой библиотеки TagLib-Sharp и мультимедийного движка FFmpeg.

## **Технологический стек**
- **Языки программирования**: C# (.NET 9.0), C++
- **Интерфейс**: WPF, XAML, Пакетная таблица файлов с функцией быстрого редактирования
- **Библиотеки метаданных**: TagLib-Sharp, FFmpeg API, ImageSharp

## **Ключевые возможности**
- **Пакетное редактирование любых тегов**: Артист, альбом, название трека, номер, год, жанр, композитор, текст песни (LRC).
- **Работа с обложками альбомов**: Встраивание, извлечение, масштабирование и удаление обложек из аудиофайлов.
- **Автоматическое переименование по шаблону**: Переименование файлов на диске по маске, например: `{TrackNumber}. {Artist} - {Title}`.
- **Парсер информации из имен файлов**: Автоматическое заполнение тегов из структуры каталогов и названий треков.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_TAG_EDITOR_<версия>_Setup.exe` или архив `STORM_TAG_EDITOR_<версия>.zip` со страницы **Releases**.
2. Перетащите аудиофайлы или папки с музыкой в окно программы и приступайте к редактированию.
